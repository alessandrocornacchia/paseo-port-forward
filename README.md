# paseo-port-forward

A Paseo plugin that adds a **Ports** tab to the workspace panel and forwards ports open on a remote Paseo host to your laptop's `localhost`, similar to VS Code Remote's port forwarding.

The plugin runs only on your laptop's Paseo daemon. It reaches remote hosts over your own SSH connection, so it also works for hosts you connect to through the Paseo relay.

Status: design phase. See the plan in the issues.
